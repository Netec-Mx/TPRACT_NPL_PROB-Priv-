# NPL con modelos probabilísticos

## Plataforma de laboratorios

Te damos la bienvenida a la **plataforma de laboratorios** del curso **NPL con modelos probabilísticos**. Aquí aplicarás técnicas de procesamiento del lenguaje natural para construir un asistente que corrija errores de escritura y sugiera cómo continuar mensajes bancarios sintéticos, mediante una práctica guiada con Python en Visual Studio Code.

## Lista de laboratorios

Cada uno de estos laboratorios está diseñado para ofrecerte una experiencia práctica. Haz clic en los enlaces para comenzar.

## Capítulo 1

### [Práctica 1. Construcción de un asistente probabilístico para corregir y autocompletar mensajes bancarios](Capitulo01/README.md)

- **Descripción**: Construye en un cuaderno de Jupyter un asistente para corregir y autocompletar mensajes bancarios sintéticos. Prepara los textos, propone correcciones mediante distancia de edición y frecuencias de palabras, y genera sugerencias con un modelo de bigramas, suavizado de Laplace y tratamiento de palabras desconocidas. Finalmente, evalúa la cobertura del vocabulario, los aciertos y la perplejidad, e integra las funciones en un prototipo probado con diez frases.
- ⏱️ **Duración estimada**: 105 min (1 hora y 45 minutos).
- 📁 **Prerrequisitos**: [Preparación del entorno de laboratorio](Capitulo01/Prerrequisitos.md).
